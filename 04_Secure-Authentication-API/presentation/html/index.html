04 · HLD & LLD DESIGN

Low-Level Design — Two Deep Dives

token_service.py — refresh rotation

1decode_token — rejects bad signature/expiry
2type == "refresh" — rejects wrong-typed tokens
3is_blacklisted(jti) — rejects replay
4blacklist(jti) — revokes before reissue
Invariant: a given refresh jti can be redeemed at most once.

dependencies.py — RBAC chain

1Extract bearer token from header
2get_current_user decodes + validates
3get_by_id — fetches the LIVE DB row
4require_role — checked against that row
Invariant: role is re-derived from the DB every request — never the JWT claim alone.

backend/app/core/dependencies.py

def get_current_admin_user(
    user: User = Depends(get_current_user)
) -> User:
    require_role(user, Role.ADMIN)
    return user
